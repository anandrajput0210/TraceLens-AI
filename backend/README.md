# TraceLens AI

> From security findings to the risks that actually matter.

TraceLens AI is a contextual security analysis platform that detects security
findings and prioritizes them using application environment, exposure,
reachability, and contextual risk.

## Core idea

Security findings aren't equal.

TraceLens connects security findings to application context to explain
which risks matter most and why.
